MiraBridge for Windows Help

MiraBridge exposes a Windows computer as a remote native tool runtime for an Agent reasoning on macOS. The Agent loop stays on the Mac; Windows only executes structured operations.

2.0.0-rc.3 is unsigned. SmartScreen may show an unknown-publisher warning. Download only from the official GitHub Release and compare its SHA-256 manifest.

First setup in ten minutes

  1. Run Setup and open MiraBridge.
  2. Keep the default allowed root, click Install / Repair, and approve one UAC prompt.
  3. On the Mac, ask Codex to run mirabridge pair create.
  4. Paste the request on Windows and create a response.
  5. Return the response to mirabridge pair accept <response> on the Mac.

What each page is for

  • Overview: confirm readiness and see connection, active Jobs, storage, and enabled capabilities.
  • Connect Mac: complete the two-code pairing flow and revoke Macs you no longer use.
  • Access: control allowed folders, Desktop, Recycle Bin scans, and local web verification.
  • Tools & maintenance: install optional tools, check updates, create redacted diagnostics, and uninstall.

Not Ready

  • OpenSSH: use Repair. MiraBridge owns only its marked config block and LocalSubnet firewall rule. It stops on AllowUsers/DenyUsers conflicts.
  • Worker: verify runtime\node\node.exe and runtime\worker\index.cjs exist in the app directory, then repair.
  • Host fingerprint: never bypass the Mac's live keyscan match. A pairing code is not a password and does not replace host verification.

Optional tools

Use the WinGet buttons first. If WinGet is unavailable, use only the linked official sources: Git, PowerShell, Python, Node.js, .NET, and FFmpeg. MiraBridge never installs or updates GPU drivers.

Security and data

The administrator-first route does not grant unlimited file access. File tools still enforce allowed roots, Desktop capability, CAS and Mac approval. Recycle Bin emptying requires a fresh scan credential. Worker retention and the 10 GiB quota govern logs. The app is isolated under a RID-specific Velopack root (%LOCALAPPDATA%\MiraBridge.Windows on x64, .ARM64 suffix on ARM64); durable Worker data stays under %LOCALAPPDATA%\MiraBridge. Normal uninstall preserves that data; full removal must be explicit.

Report an issue

Create and review a redacted diagnostic preview, then open a GitHub Issue yourself. MiraBridge sends no background telemetry.
